## Types of Replacements

### Python Patterns
```python
# Before
order_id = data.get('orderId')
product_id = item['productId']
metadata = {'orderId': order_id, 'updatedAt': timestamp}

# After

product_id = item[Fields.PRODUCT_ID]
metadata = {Fields.ORDER_ID: order_id, Fields.UPDATED_AT: timestamp}
```

### Dart Patterns
