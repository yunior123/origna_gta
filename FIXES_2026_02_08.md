# Fixes Applied — 2026-02-08

## Summary

## Changes Made

### 1. Inventory Config Always Persisted ✅
**File:** `origna_gta/lib/screens/addproduct_screen.dart` (lines 1423-1429)

**Problem:** Inventory settings (`_inventoryManaged`, `_trackQuantity`, `_allowBackorder`) were only persisted when they differed from defaults. If user kept defaults (managed=true, trackQuantity=true), `inventoryConfig` was null and settings were lost.

**Fix:** Always create `InventoryConfig` object regardless of values.

```dart
// Before: Only created config when different from defaults
InventoryConfig? inventoryConfig;
if (!_inventoryManaged || !_trackQuantity || _allowBackorder || ...) {
  inventoryConfig = InventoryConfig(...);
}

// After: Always create config
final inventoryConfig = InventoryConfig(
  managed: _inventoryManaged,
  trackQuantity: _trackQuantity,
  allowBackorder: _allowBackorder,
  lowStockThreshold: int.tryParse(_lowStockThresholdController.text) ?? 5,
);
```

### 2. Apartment Field UI Added ✅
**File:** `origna_gta/lib/screens/addproduct_screen.dart` (lines 513-519)

**Problem:** `_apartmentController` was declared but no TextField was rendered. Users couldn't specify apartment/unit numbers.

**Fix:** Added TextField between Street and City fields.

```dart
_buildGlassTextField(
  controller: _apartmentController,
  label: 'Apartment / Unit (Optional)',
  icon: Icons.apartment_rounded,
  hint: 'e.g., Suite 100, Unit 5B',
),
```

---

### 3. Discount Tier Validation ✅
**File:** `origna_gta/lib/screens/addproduct_screen.dart` (lines 1392-1403)

**Problem:** UI allowed setting 3+ items = 50% off, 5+ items = 20% off (decreasing discount for higher quantity).

**Fix:** Added validation in submit button that shows error if 5+ discount < 3+ discount.

```dart
final discount3 = double.tryParse(_shippingDiscount3Controller.text);
final discount5 = double.tryParse(_shippingDiscount5Controller.text);
if (discount3 != null && discount5 != null && discount5 < discount3) {
  ScaffoldMessenger.of(context).showSnackBar(
    const SnackBar(
      content: Text('5+ items discount must be ≥ 3+ items discount'),
      backgroundColor: DesignTokens.error,
    ),
  );
  return;
}
```

---

### 4. Hide Free Shipping Toggle for Digital Products ✅
**File:** `origna_gta/lib/screens/addproduct_screen.dart` (lines 312-323)

**Problem:** Free Shipping toggle was visible for digital products even though it's forced to true (digital products have no shipping).

**Fix:** Wrapped toggle in conditional `if (!state.isDigital)`.

```dart
if (!state.isDigital)
  Expanded(
    child: _buildGlassToggle(
      label: 'Free Shipping',
      // ... rest of toggle
    ),
  ),
```

**Layout:** When digital, row only shows Min Order Qty (full width). When physical, shows both fields.
