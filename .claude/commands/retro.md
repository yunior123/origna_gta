# /retro — Session Retrospective

**Usage**: `/retro`

Reflect on the current session's work and save learnings for future sessions.

## Process

### 1. Review What Happened
- What tasks were completed this session?
- What files were modified?
- What commits were made?

### 2. What Went Well
- Approaches that worked
- Tools/patterns that saved time
- Clean code produced

### 3. What Didn't Go Well
- Blockers encountered
- Wrong approaches tried first
- Time wasted on dead ends

### 4. Lessons Learned
- What would you do differently next time?
- New patterns discovered?
- Anti-patterns to avoid?

### 5. Save to Memory
For each significant learning, save to the appropriate memory file:
- **feedback** memories for workflow improvements
- **project** memories for state/decisions
- **user** memories for preference updates

### 6. Update STATE.md
Add any decisions or blockers to STATE.md for the next session.

## Output Format
```
## Session Retro — [Date]

### Completed
- [x] Task 1
- [x] Task 2

### Went Well
- ...

### Could Improve
- ...

### Learnings Saved
- feedback: ...
- project: ...
```
