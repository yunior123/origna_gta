## CRITICAL ISSUES

### 1. HARDCODED WAITS (CRITICAL)
- **Found**: 223 instances of `await new Promise(r => setTimeout(r, X))`
- **Impact**: Tests 5–10 min slower, flaky on loaded CI
- **Fix**: Replace with `waitForChange({ timeout: 10_000 })`

### 2. MISSING TEST ISOLATION (HIGH)
- **Problem**: Only 2 `clearState()` calls in 74 files
- **Impact**: Cannot parallelize, test order matters, state leaks
- **Fix**: Add `beforeEach(() => browser.clearState())` to all 74 files

### 3. COOKIE/STATE PERSISTENCE BUG (HIGH)
- **Known**: Stripe session ID persists across tests
- **Symptom**: Payment loops, 3DS replay, order dependency
- **Current workaround**: workers: 1 (single-threaded)
- **Proper fix**: clearState() in setup

## FLAKY TEST PATTERNS

1. **Stripe form interaction**: Agent-browser can't interact with iframes; workaround uses backend API
2. **Browser state reuse**: Cookies persist; tests fail in different order
3. **Hardcoded wait races**: Sleep ends before UI updates, check fails silently
4. **Seed data validation**: Tests assume e2e_product_test_seller exists, fail silently if missing
5. **Webhook timing**: Polls every 3s (slow), test PASSES even if webhook never fires (wrong!)
6. **Rate limiting**: No retry logic; concurrent tests hit 429

## TEST SPEC VS FLUTTER MISMATCH

### Outdated Semantics (MEDIUM)
- Tests use loose regex: `/admin-tab-reviews|reviews|avis/i`
- If Flutter renames "admin-tab-reviews" → "admin-reviews-tab", tests break
- Multiple fallback labels suggest labels are inconsistent

### Missing UI Screens (MEDIUM)
- Tests search for screens that may not exist (admin reviews tab, support agent, security logs)
- Tests silently pass with "empty is valid" logic (wrong approach)

### Semantic Label Drift (MEDIUM)
- Example: `/login_email_field|you@example|vous@exemple/`
- Suggests labels changed or are inconsistent
- Need standardization in schema_constants.dart
